# pulsr on the web

pulsr turns the sound playing on your computer into a ridge of lines that moves with the music, drawn in 3D in the browser. Play something in another tab, share that tab with the page, and watch it. It needs Chrome or Edge on a computer to share a tab's sound; other browsers can use the microphone instead.

Nothing leaves your computer: the sound is analysed in the page, and there is no server, account or analytics.

## Run it locally

```
npm install
npm run dev
```

Then open http://localhost:8137/pulsrweb/

## Tests

```
npm test
```
